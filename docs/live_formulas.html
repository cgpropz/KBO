Live projection formulas

Mode in pipeline/projection_formula.json: tuned. Coefficients are the committed Phase 2 params, not new fits.

What is live. A stat is on the tuned formula only when its params file says candidate. That is the fit shadow has been scoring. Everything else stays on the previous formula.

Roll back. Set mode to current, then rerun Refresh Data & Deploy to Vercel for KBO (deploy.yml), Refresh WNBA Data or Refresh WNBA PrizePicks Lines (30 min) for WNBA, and Refresh NFL PrizePicks Board for NFL. One run can also set CG_PROJECTION_FORMULA=current without editing the file.

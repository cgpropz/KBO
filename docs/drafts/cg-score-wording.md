# CG Score guide wording (draft)

Live guide text is unchanged. These are alternatives for Code Green to pick from later.

## A. Gap

CG Score is the gap between our projection and the posted line, with the matchup folded in. A score near 50 means the projection and the line are close. Farther from 50 means a wider gap. It is not a probability that the prop hits.

## B. Side

CG Score says which side the projection sits on. Above 50 points to the over. Below 50 points to the under. The distance from 50 is the size of that gap. It is not a probability that the prop hits.

## C. Plain

CG Score compares our number with the posted number and adjusts for the matchup. Use it to see the gap, then read the hit rate and the game log. It is not a probability that the prop hits.

Privacy

This notice is published by [LEGAL ENTITY NAME]. Mailing address: [CONTACT ADDRESS]. The name and address are placeholders until they are supplied. This page describes how the site works today. It does not add a retention period or other privacy terms that are not already part of the product.

Account

Sign-in uses an email and password through Supabase. When you create an account, marketing codes from the link you arrived on (such as utm tags) and the time you confirmed you are 21 or older can be saved with that account.

Payments

Card checkout is handled by Stripe. If you are signed in, checkout can send your account id and email so the payment can be matched to the account. If you are not signed in, Stripe collects the email and access is matched when you later sign up with that email.

What this browser stores

This browser can store the marketing codes from your visit, the time you confirmed you are 21 or older, and a note of purchase events already sent. That age confirmation stays in this browser so you are not asked again on this device.

Advertising measurement

An X (Twitter) pixel can record a sign-up and a purchase.

Site analytics

Two tools measure how the site is used: Vercel Web Analytics and PostHog. Neither one receives your name, email, password, account id or payment details.

Vercel Web Analytics counts page views. For each page view Vercel can record the page address, the referring site, and the browser, operating system, device type and approximate location that it derives from the request. Before a page address is sent, the site removes every query parameter except a sport name and marketing codes (utm tags) made only of letters, numbers, dashes and underscores, so session ids, tokens, email addresses and ad click IDs are not sent. Vercel Web Analytics does not use cookies. Vercel tells visitors apart with a hash of the request that it discards after 24 hours. It does not check Do Not Track or Global Privacy Control.

PostHog records four events, each with fixed values only:

  • free_top3_view: the free top 3 preview came into view, with the sport.
  • checkout_click: a checkout button was pressed, with the plan and the sport.
  • signup: a new account sign-up was accepted, with no other details.
  • discord_plan_click: a Discord Only plan button was pressed, with the plan.

Each event also carries the page address, cleaned the same way as for Vercel, the referring site and search engine, cleaned the same way, and browser details such as browser, operating system, screen size, language and time zone. Marketing codes that are not plain letters and numbers, and ad click IDs such as gclid, fbclid and twclid, are removed before anything is sent. PostHog does not capture clicks automatically, does not record sessions, and does not build a profile of you; the site never tells PostHog who you are. PostHog keeps its state in memory only, so it sets no cookies and writes nothing to local storage, and its random visitor id is replaced on the next page load. If your browser sends Do Not Track or Global Privacy Control, PostHog is not loaded and no events are sent. The CGPropz PostHog project is set to discard client IP addresses.
